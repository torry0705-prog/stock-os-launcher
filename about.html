stock-os

stock-os 는 개인 한 사람이 자기 컴퓨터에서 쓰는 도구입니다. 다른 사람에게 제공하는 서비스가 아닙니다.

구글 계정을 쓰는 곳

사용자 본인의 컴퓨터가 30분마다 요약 파일 1개를 사용자 본인의 구글 드라이브에 올립니다. 권한은 drive.file(이 앱이 만든 파일만) 하나뿐이라, 드라이브의 다른 파일은 보거나 바꿀 수 없습니다.

개인정보 처리: 개인정보 처리방침

English

stock-os is a personal tool run by one person on their own computer; it is not offered to others. It uploads one summary file to the user's own Google Drive every 30 minutes, using only the drive.file scope (files created by this app). See the privacy policy.
