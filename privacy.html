stock-os 개인정보 처리방침

시행일: 2026-10-31

  • stock-os 는 사용자 본인 한 사람만 쓰는 개인 도구입니다.
  • 구글 권한은 drive.file 하나입니다. 이 앱이 사용자 드라이브에 만든 파일만 만들고 고칩니다. 다른 파일은 읽지 않습니다.
  • 구글에서 받는 정보는 로그인한 계정의 이메일 주소뿐이며, 맞는 계정인지 확인하는 데만 씁니다.
  • 인증 정보는 사용자 본인 컴퓨터에만 저장됩니다. 개발자나 다른 서버로 보내지 않습니다.
  • 어떤 정보도 팔거나 남과 나누거나 광고에 쓰지 않습니다.
  • 구글 계정 설정의 '타사 앱 및 서비스'에서 언제든 접근 권한을 해제할 수 있습니다.

Google API 에서 받은 정보의 사용은 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.

English

  • stock-os is a personal tool used only by its owner.
  • It requests one Google scope, drive.file, and only creates and updates files it made in the user's own Drive. It does not read other files.
  • The only other data received is the signed-in account's email address, used solely to confirm the right account.
  • Credentials are stored only on the user's own computer and are never sent to the developer or any other server.
  • No data is sold, shared, or used for advertising.
  • Access can be revoked at any time under "Third-party apps & services" in the Google Account settings.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
